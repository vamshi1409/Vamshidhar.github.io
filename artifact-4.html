Title

Data Challenge Scenarios – Responsible Machine Learning

Introduction

Machine learning models depend on the quality of the data used to train them. Even when a model produces accurate results, problems with data quality, bias, and privacy can affect how reliable those results are.

For my fourth portfolio artifact, I selected the Data Challenge Scenarios activity from my Machine Learning Fundamentals course. In this activity, I explored three scenarios involving customer reviews, employee hiring, and healthcare. Each scenario helped me understand different challenges that organizations face when developing and using machine learning systems.

Through this activity, I learned that building a successful machine learning model is not just about achieving high accuracy. It is also important to evaluate the data, identify potential bias, protect sensitive information, and carefully test the model before using it in real-world situations.

The Documentation

The completed 4.3 Data Challenge Scenarios assignment is included below as evidence of my coursework. It contains an AI-generated summary of my scenario responses and my personal reflection.

Description

Scenario 1 – Data Quality and Cleaning: I explored how to prepare customer review data by identifying spam, handling missing information, removing duplicates, and checking sentiment labels. I also learned that removing too much data could exclude genuine customer opinions.

Scenario 2 – Bias and Model Evaluation: I evaluated a hiring model that achieved 89% overall accuracy but only 68% accuracy for Group C. This helped me understand why checking model performance across different groups is important and how bias can affect hiring decisions.

Scenario 3 – Privacy and Healthcare AI: I explored how hospitals could collaborate on machine learning while protecting patient information. I learned about federated learning, privacy safeguards, and why a model must be tested separately in different healthcare environments.

These scenarios helped me understand how data quality, fairness, and privacy affect the reliability of machine learning systems.

Objective

The objective of this activity was to understand the challenges that organizations face when developing and using machine learning models. I wanted to learn how data quality, bias, and privacy can affect model performance and reliability.

Through these scenarios, my goal was to practice identifying potential problems, evaluating model results, and suggesting ways to improve machine learning systems before they are used in real-world situations.

Process

I completed this activity by working through three interactive scenarios involving data quality, bias, and privacy in machine learning.

First, I reviewed each scenario, identified the main problem, and suggested possible solutions based on my understanding of machine learning concepts. After submitting my responses, I received follow-up questions that helped me think more carefully about my decisions.

For example, in the customer review scenario, I initially focused on cleaning the data. However, when I was asked what would happen if 30% of the reviews were removed, I realized that some genuine customer opinions might also be lost.

In the hiring scenario, I examined differences in model accuracy between groups and considered how incorrect predictions could affect qualified applicants. In the healthcare scenario, I explored ways to protect patient information and evaluate model performance across different hospitals.

Finally, I reviewed the AI-generated summary of my responses and wrote a personal reflection about what I learned from the activity.

  • Microsoft Word: Used to document the completed activity and my personal reflection.

Value Proposition

This artifact demonstrates my ability to identify and understand important challenges in machine learning, including data quality, bias, and privacy. It shows how I approach problems, evaluate model results, and consider possible improvements before an AI system is used in real-world situations.

Through this activity, I learned that achieving high accuracy is not enough to make a machine learning model reliable. It is also important to understand how the model affects different groups, protect sensitive information, and make sure the results are consistent and fair.

These skills are valuable for organizations developing AI applications because they help improve reliability, reduce risks, and support responsible decision-making.

Unique Value

As a Full Stack .NET Developer, I have experience developing applications, testing features, and identifying issues before releasing them to users. This activity helped me connect my software development experience with machine learning concepts.

In traditional software development, I usually test whether an application works correctly for different inputs. Through this activity, I learned that evaluating machine learning models also involves checking data quality, identifying bias, and understanding how predictions affect different groups of people.

I believe my software development background, combined with my growing knowledge of AI and machine learning, will help me contribute to building applications that are more reliable, fair, and useful for users.

Relevance

This artifact is relevant to software developers, data engineers, AI/ML professionals, and organizations that use machine learning in their applications.

The scenarios demonstrate how challenges such as poor data quality, bias, and privacy concerns can affect machine learning results. They also highlight why organizations need to evaluate models carefully before using them to make important decisions.

As I continue learning about AI and machine learning, I can apply these concepts to my future projects by focusing on data quality, proper testing, fairness, and responsible use of AI systems.
